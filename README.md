 # Seasonal Knowledge Explorer

## Description

The Seasonal Knowledge Explorer is an interactive Python application that allows users to explore published Indigenous seasonal information and investigate weather observations.

## Intended Users

The application is designed for educational users who want to explore published seasonal knowledge and associated weather patterns.

## Technologies

- Python
- Streamlit
- Pandas
- Matplotlib
- Pytest

## How to Install

Create a virtual environment:

```bash
python3 -m venv .venv
```
